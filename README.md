# Assets

Centralized asset storage repository for media files used by portfolio and blog projects.

## Directory Structure

```
images/
  blog/           # Blog post images
  portfolio/      # Portfolio project images (Alignment, Comeback, Connector, etc.)
  shared/         # Common assets (logos, headshots)
pdfs/
  presentations/  # Presentation files
```

## Conventions

- **Format:** WebP preferred for web optimization
- **Naming:** `Category_description.webp` (e.g., `Blog_technicalfoundations.webp`)
- **Git LFS** enabled for binary file handling
