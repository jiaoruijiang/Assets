## Repository Purpose

Centralized asset storage repository for media files (images, PDFs) used by portfolio and blog projects. This is not a code repository - it contains only static assets.

## Directory Structure

- **images/blog/** - Blog post images
- **images/portfolio/** - Portfolio project images (organized by project name: Alignment, Comeback, Connector, Knowledge, Mentoring, NotShipping, Skeptics)
- **images/shared/** - Common assets (logos, headshots)
- **pdfs/** - Resume and presentation PDFs

## Conventions

- **Image format:** WebP preferred for web optimization
- **Naming pattern:** `Category_description.webp` (e.g., `Blog_technicalfoundations.webp`, `About_magic.webp`)
- **Git LFS** is enabled for binary file handling
